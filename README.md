# Web Development 2026 – Modo claro y oscuro

## Descripción
Ejercicio de HTML, CSS y JavaScript que implementa un modo claro/oscuro y manejo de almacenamiento del navegador.

## Funcionalidades
- Botón para cambiar entre modo claro y modo oscuro.
- `localStorage`: guarda la preferencia de tema para conservarla al volver a abrir la página.
- `sessionStorage`: registra las visitas realizadas durante la sesión actual.
- Diseño responsive basado en Bootstrap.

## Archivos principales
- `index.html`: estructura de la página y botón de cambio de tema.
- `css/styles.css`: estilos de Bootstrap y personalización de los temas.
- `js/scripts.js`: lógica JavaScript para `localStorage` y `sessionStorage`.

## Ejecución
Abrir `index.html` en un navegador moderno. No requiere servidor para las funcionalidades principales.

## Entrega
Subir esta carpeta a un repositorio público de GitHub y entregar la URL del repositorio.
