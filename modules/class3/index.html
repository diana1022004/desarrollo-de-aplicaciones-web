Procesar solicitud

Una biblioteca recibe las solicitudes de préstamo como un array: el primer elemento es el nombre del usuario y los demás son los títulos de los libros que quiere. La función procesarSolicitud reorganiza ese array.

Las reglas del sistema

  1. Sacar el nombre del usuario (el primer elemento) con shift().
  2. Añadir al inicio la cadena "Carné de socio" con unshift().
  3. Añadir al final el nombre del usuario con push().
  4. Devolver el array modificado.

Pruébala

Escribe un título por línea.
