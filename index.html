Lo que se aprende en la clase

Un curso para tener experiencia práctica en desarrollo web front-end. Se parte de los fundamentos de HTML, CSS y JavaScript y se llega al uso de librerías y frameworks como React.js.

La teoría se combina con práctica, con proyectos individuales y en equipo para aplicar lo aprendido en situaciones reales.

HTML semántico
Páginas bien estructuradas y accesibles.
CSS responsive
Diseños que se adaptan al celular, la tablet y el computador.
JavaScript
Lógica, arrays, eventos y manejo del DOM.
localStorage y sessionStorage
Guardar preferencias y datos en el navegador.
Git y GitHub
Control de versiones y publicación con GitHub Pages.
React.js
Parte del programa del curso.
